# 💳 Credit Card Financial Analytics Dashboard

## 📌 Project Overview
An interactive Power BI dashboard designed to analyze credit card transactions and customer behavior. The project provides insights into revenue, transaction patterns, customer demographics, and spending trends.

## 🎯 Objectives
- Analyze credit card transaction data.
- Understand customer spending behavior.
- Monitor key financial performance indicators.
- Identify weekly and monthly revenue trends.
- Support data-driven business decisions.

## 🛠️ Tech Stack
- **Power BI** – Dashboard development and visualization
- **SQL** – Data querying and analysis
- **CSV** – Dataset storage and management
- **DAX** – To be documented after verifying the measures used
- **Power Query** – To be documented after verifying transformations

## 📊 Key Analysis Areas
- Revenue analysis
- Transaction amount and transaction count
- Customer segmentation
- Card category analysis
- Weekly and monthly trends
- Customer demographic analysis

## 📁 Project Structure
- `credit_card_report.pbix` – Power BI dashboard
- `SQL Query - Financial Dashboard Data.sql` – SQL queries
- `credit_card.csv` – Credit card dataset
- `customer.csv` – Customer dataset
- `cc_add.csv` – Additional credit card data
- `cust_add.csv` – Additional customer data
- PDF files – Dashboard reports and exports

## 🚀 Getting Started
1. Clone this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Explore the dashboard and available visualizations.
4. Review the SQL queries to understand the data analysis.

## 📈 Business Value
The dashboard helps users understand financial performance, identify customer spending patterns, and derive actionable insights from transaction data.
